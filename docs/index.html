A latent communication fabric

LatentMesh

Agents converting everything they know into language before talking to each other is a bottleneck, not a law of nature. LatentMesh tests what happens when a hidden state — not its serialization — becomes the network primitive. No edge is trusted by default: a connection only earns execution authority after surviving a counterfactual test proving it moved real information.

03 — measured, not asserted

The alignment fit was 964× too slow, so it got fixed

A dense SVD is O(d³) — at a realistic 4096-dim hidden size it cost 156 seconds. The calibration set only has rank ≤ n ≈ 16–64, so an exact O(d²n) reformulation (QR + a small SVD) gets the identical answer in milliseconds — proven identical by test, not assumed.

Same run: 16×4096-dim vectors are 256 KiB at F32, 128.0 KiB at F16, 64.1 KiB at Int8 — the exact scaling this protocol was built to test, now backed by a measurement instead of a guess. Full table in latentmesh-bench.

honest status

This is a research prototype. What's real: the packet/codec types, the alignment algorithm — correctness and the 964× speedup, both proven by test — the causal-verification statistics, and the admission gate. What isn't: any live open-weight model integration, any MidStream/RuVector/Radio/MetaHarness/RVF/RVM wiring, and every specific figure attributed to external literature in the ADRs — attributed, not reproduced.
