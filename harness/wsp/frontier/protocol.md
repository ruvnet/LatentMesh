# Registered comparison of single frame weight programs and distillation

## Decision and scope

Register before tuning the confidence gate or computing any new test scores. The candidate distills all 416 teacher responses into 47 receiver coordinates and a bias with a closed form solve. It sends those 48 parameters as signed int8 values and one float32 scale. The hypothesis is that allocating bytes to parameters improves on sending public probe responses at the same wire cost. The operating point must also protect the receiver's original sentiment decisions.

The point gate is at least two percentage points in balanced anger accuracy above every compact comparator and at most one point of lost native sentiment accuracy on **each** of two fresh populations. For an evidence claim beyond a point estimate, also require simultaneous one sided lower bounds above two points for every paired advantage and upper bounds below one point for lost retention. Use 20,000 paired, label stratified bootstrap replicates per contrast, seed 72191, Bonferroni tail 0.05 divided by twice the number of controls plus two retention bounds. Use the one sided exact Clopper Pearson upper bound for the probability of displacing a correct native decision. Bootstrap intervals are approximate. No interim stopping, threshold revisions or test based model selection.

A separate public benchmark reports four class macro F1 over **every** official TweetEval emotion test row in file order. Run the quantized Cardiff emotion specialist intact and with the locked candidate overriding only to anger. Also report the compact controls on that same scaffold. Compare with the official repository's listed TimeLMs 2021 emotion score of 80.2 and BERTweet's 79.3. A historical leaderboard entry is a reference, not a census of every contemporary system. The public endpoint has an extra pretrained model and a different metric from the one frame binary transfer endpoint. A claim about that published reference additionally requires the candidate to exceed 80.2 and the intact specialist, with a positive paired 95% bootstrap lower bound against the intact specialist. The published table has no example level TimeLMs predictions here.

## Arms and identical information budgets

All transferred arms get a 52 byte payload, identical signed application headers and a C Air loopback. Publish per arm observed sizes. The public method ID declares the codec. Bind the public setup and a locally trusted Ed25519 key. No fitted thresholds or sender dependent hints travel out of band. Calibrate each of the received models at the receiver. Receipt fingerprints are for verification only. Count shared text and receiver features separately from warm packet cost. Both parties must already possess the receiver feature map or compute it. This does not establish zero cost transfer to an unknown model.

| Method | Fixed construction |
| --- | --- |
| WSP candidate | WSP ridge on all 416 full teacher scores plus local and protection rows, width 47. Send the 48 signed int8 coefficients with one common float32 scale. |
| Soft distillation | Same 416 soft scores, public local and protection rows, width 47 and coefficient codec. Minimize mean binary soft target cross entropy with L2 0.01 on weights, bias unpenalized, L-BFGS. |
| Direct float | WSP on all 416 soft scores, local and protection rows in the first 12 receiver coordinates. Send 13 float32 parameters. |
| Packed hard | 416 teacher signs, one bit each, fitted by WSP at the receiver. |
| Binary four bit | 104 evenly quantized soft scores, two per byte, fitted at the receiver. |
| Printable four bit | 78 soft scores, packed as 39 bytes and base64 encoded into 52 printable bytes. |
| Eight bit observations | 48 signed observations and a float32 scale. |
| Local | No transmitted bytes. Fit only the 160 shared gold labels and the protection rows. |
| Intact | No new output. Retain native decisions. |

For the four response codecs, use the ordered prefix that fits, the same width 47, and the same public local and protection rows. WSP uses the pinned ruv-FANN solver. Append local +1 or -1 and protection -1 before fitting. Use an unquantized 48 parameter sender fit as an oracle diagnostic for rounding error, excluded from compact competitors. For width 12 also check the closed form identity between 13 target moments and the ridge coefficients using the same column normalization, regularizer and bias. This is an algebraic diagnostic, not an extra source of evidence for accuracy.

For each arm independently, allow an override for all native classes or only native negative. Enumerate all unique calibration scores plus always and never cutoffs, using strict score greater than threshold. Maximize balanced skill accuracy subject to at most 0.5 percentage point empirical retained loss on calibration. Break ties by fewer lost retained cases, then fewer total overrides, all classes before negative only, then the largest threshold. A rejected override returns the original three class sentiment decision. Count every lost correct native decision, including negatives overridden by anger. Apply one frozen policy per arm to both test populations and to the official four class scaffold.
