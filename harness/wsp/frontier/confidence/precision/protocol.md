# Prospective all emotion precision check

The selected 13 float receiver improved anger versus sadness recognition, but only about one fifth of tags on natural dialogue were anger. The two class fitting task excluded neutral, joy, surprise, fear and disgust. Test that failure mode with a separate, opt in anger output. This follow up is registered after seeing the earlier results and before computing new fitting values or reviewing labels or predictions on the new test dialogues. The prior automatic override decision stands.

Use the same pinned MELD and CARER, GoEmotions, TweetEval and receiver assets. Reconstruct the earlier matched MELD development split. The new training pool includes only complete training dialogues containing at least one of the former matched fit examples. The threshold selection pool includes only dialogues containing a former matched selection example. The new test includes only entire official MELD train dialogues in neither pool. Exclude normalized text found in all old external data and all official MELD dev and test texts. Deduplicate internally in source order. Report exact row counts, dialogue counts, ID hashes, positives and negatives for all three new populations. Test dialogues are unseen by experiment fitting and threshold selection, although all three populations come from the same TV series. Earlier membership and overlap checks processed public texts.

Use three coefficient linear WSP programs with two inputs, the frozen receiver score and max native sentiment softmax. Fit on up to 192 hash ranked angry utterances and up to 576 hash ranked nonangry utterances pooled across all other emotions. Rank by SHA256 of UTF8 `receiver-precision-v1/` plus the row ID. Use +1 and −1 and the parent ruv-FANN closed form solver. Compare 13 floats, 48 signed coefficients, soft distillation, the no wire local head, a 13 float score only ablation and a native confidence only control. Use the identical inputs, label budget and rule for each.

Use the natural class mix in every eligible threshold selection dialogue. The primary operating point maximizes F0.5, or 1.25 TP / (1.25 TP + 0.25 FN + FP), among thresholds emitting at least 20 tags. Break ties by greater precision, then recall, then the largest threshold. A stricter secondary operating point maximizes recall among thresholds with empirical precision at least 50% and at least 20 flags, ties by greater precision then the largest threshold. Disable this tag if no threshold qualifies. Include both previously locked 13 float anger versus sadness tags (social calibration and dialogue calibration), unchanged, as comparators on the same new test dialogues.

Freeze the three coefficients for each operating point before extracting test features. Publish precision, recall, F0.5, F1, TP, FP, FN, tag count and the number of correct native decisions an exclusive override would have displaced. A separate tag preserves the original sentiment output by construction. For precision or F0.5 improvements against the previous dialogue calibrated 13 float tag, report paired 95% intervals from 10,000 dialogue bootstrap draws, seed 51873. Report undefined precision for a method with no flags. A claim that precision improved requires a positive paired lower bound. Fifty percent precision and 20% anger recall on new data are descriptive utility thresholds. Do not promote automatic routing.
