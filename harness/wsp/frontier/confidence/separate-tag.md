# Additional operating point, registered before test predictions

After the original fits on development data, the protected WSP policy selected a constant negative override for both the social and dialogue calibration. The primary protocol and its controls stand. No evaluation features, predictions or scores have been opened. Add this separate, secondary operating point before fitting it.

When a caller requests a second emotion output, correctly predicted sentiment alone is not evidence that anger is absent. Fit another three parameter local WSP program from the same score and confidence using only the 384 labeled emotion training examples, with +1 for anger and −1 for sadness. Select its threshold using the same 192 separate emotion labels, maximizing balanced accuracy, then minimizing the number of positive decisions, then choosing the largest threshold. Use this construction for every transferred arm, the WSP score only ablation and native confidence only. All arms have access to the same labels. A returning anger tag never replaces original sentiment. Expose the tag separately in a real inference path and also report the damage if it were treated as an exclusive route.

Report paired changes versus the older receiver and 13 floats on the fresh social and MELD panels. For MELD, compute an oracle bound for exclusive routing with a one percentage point native loss limit. An oracle can accept every angry utterance where native sentiment is wrong, plus at most floor(0.01 times all protected utterances) angry cases with correct native sentiment. Correctly rejecting every sad case makes (1 plus that maximum anger recall) / 2 an upper bound on balanced accuracy. This bound is descriptive and never sets a threshold. No promotion or superiority claim will be made from this secondary outcome.
